# Lost Letters

เกมฝึกอ่านและเขียนตอบอีเมลภาษาอังกฤษแบบ Pixel/Retro มีจดหมาย 10 หมวด หมวดละ 3 ระดับ (A2, B1, B2) รวม 30 สถานการณ์ พร้อมคำใบ้ คำศัพท์ word count คะแนน และ XP

หลังตรวจคำตอบ เกมจะแสดงใบหน้าพิกเซล 4 อารมณ์และคำอธิบายว่า *ผู้อ่านอาจรู้สึกอย่างไร* ซึ่งเป็นการตีความจากคำตอบ ไม่ใช่ความรู้สึกจริงของบุคคล ในโหมด Ollama โมเดลจะประเมินเหตุผล หากโมเดลส่งข้อมูลส่วนนี้มาไม่ครบ เกมจะระบุว่าเป็นการประมาณแทน

## เริ่มเล่นบน Windows

1. ติดตั้ง [Python 3](https://www.python.org/downloads/windows/) และ [Ollama](https://ollama.com/download/windows/) หากต้องการให้ AI ตรวจจริง
2. ถ้าจะใช้ Ollama ให้เปิด Ollama แล้วดาวน์โหลดโมเดลที่รองรับภาษาอังกฤษ เช่น `ollama pull llama3.2` (โมเดลอื่นก็ใช้ได้)
3. ดับเบิลคลิก `start.bat` ไฟล์นี้จะหา Python ที่ติดตั้งทั่วไปก่อน แล้วลองใช้ Python ที่มากับ Codex บนเครื่องนี้ หากเปิดจาก PowerShell ให้รัน `py -3 server.py` (หรือ `python server.py`)
4. เปิด `http://127.0.0.1:8000` ในเบราว์เซอร์
5. หยุดเซิร์ฟเวอร์ด้วย `Ctrl+C`

เกมใช้ Python standard library เท่านั้น ไม่ต้อง `pip install` และไม่ต้องมีบัญชีหรือ API key หน้าเว็บกับ API ให้บริการจาก Python process เดียวกันที่ `127.0.0.1:8000` โดย backend ติดต่อ Ollama เฉพาะที่ `127.0.0.1:11434` ผ่าน `/api/tags` และ `/api/generate` เบราว์เซอร์ไม่ได้ติดต่อ Ollama โดยตรง

### เลือกโมเดลหรือพอร์ต

```powershell
$env:OLLAMA_MODEL = "llama3.2"
$env:LOST_LETTERS_PORT = "8000"
py -3 server.py
```

หากไม่กำหนด `OLLAMA_MODEL` เกมจะใช้โมเดล local ตัวแรกที่ Ollama รายงาน (ข้ามโมเดล `:cloud` และโมเดล embedding) หากกำหนดชื่อโมเดลที่ไม่มีในเครื่อง เกมจะแสดง Demo mode จนกว่าจะดาวน์โหลดโมเดลที่ตรงชื่อ แล้วกดปุ่ม `↻` ในแถบสถานะ

## สถานะการตรวจ

- **OLLAMA CONNECTED** แสดงเมื่อ backend ติดต่อ Ollama ได้และพบโมเดลจริง คะแนนที่มีป้าย `OLLAMA AI` มาจากโมเดลในเครื่อง
- **DEMO MODE** แสดงเมื่อ Ollama ใช้ไม่ได้ ไม่มีโมเดล หรือการตรวจล้มเหลว คะแนน Demo เป็นเพียงการประมาณจากความยาว ประเด็นที่ครอบคลุม และข้อผิดพลาดบางรูปแบบ ไม่ใช่การประเมินด้วย AI
- หาก AI ล้มเหลวระหว่างตรวจ เกมจะใช้ Demo estimate สำหรับคำตอบนั้นและแสดงเหตุผลแบบย่อ

คำตอบและ XP เก็บใน `localStorage` ของเบราว์เซอร์เดียวกัน ตรวจซ้ำได้แต่ XP จะได้ครั้งแรกของแต่ละจดหมายต่อระดับเท่านั้น การล้างข้อมูลเว็บไซต์ในเบราว์เซอร์จะลบความคืบหน้า

## หมายเหตุ

- คะแนน AI เป็นคำแนะนำเพื่อฝึกเขียน ไม่ใช่ผลสอบมาตรฐาน
- โมเดลขนาดเล็กอาจให้คะแนนและคำแนะนำไม่สม่ำเสมอ
- เซิร์ฟเวอร์รับเฉพาะที่ `127.0.0.1` เพื่อใช้งานบนเครื่องนี้
- ฟอนต์ Pixel โหลดจาก Google Fonts เมื่อมีอินเทอร์เน็ต หากออฟไลน์จะใช้ monospace fallback

API ของ Ollama ที่ใช้ตรงตาม [คู่มือ API ของ Ollama](https://docs.ollama.com/api): `GET /api/tags` และ `POST /api/generate` โดยส่ง `stream: false` และ `format: "json"`
