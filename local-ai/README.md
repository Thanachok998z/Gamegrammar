# Lost Letters — Local AI Edition

เวอร์ชันนี้รันบนเครื่องแยกจากเกมออนไลน์ เปิดที่ `http://127.0.0.1:8001` และใช้ Ollama ในเครื่องเพื่อตรวจคำตอบ

## เริ่มเล่นบน Windows

1. ติดตั้ง Python 3 และ Ollama
2. เปิด Ollama แล้วดาวน์โหลดโมเดล เช่น `ollama pull llama3.2`
3. ดับเบิลคลิก `start.bat` ในโฟลเดอร์นี้
4. เปิด `http://127.0.0.1:8001` ในเบราว์เซอร์

หาก Ollama ใช้ไม่ได้ เกมจะแสดง **Demo mode** อย่างชัดเจน คะแนน Demo ไม่ใช่ผลตรวจด้วย AI เมื่อ Ollama เชื่อมต่อได้ เกมจะแสดง **OLLAMA CONNECTED** และผลตรวจมีป้าย **OLLAMA AI**

ผลตรวจ AI มีคำแนะนำ จุดที่ควรแก้ คำหรือสำนวนที่เหมาะกว่า และตัวอย่างคำตอบ โมเดลจะเสนอการแก้เฉพาะข้อความที่พบในคำตอบจริง หากไม่มีข้อผิดพลาดชัดเจน ส่วนดังกล่าวจะแจ้งว่าไม่พบ

ผลตรวจเก็บใน `localStorage` ของเบราว์เซอร์นี้ สูงสุด 10 ครั้งต่อจดหมายและระดับ เลือกดูผลเก่าได้ในหัวข้อ **ผลตรวจที่บันทึกไว้** การล้างข้อมูลเว็บไซต์จะลบผลตรวจที่บันทึกไว้

ใช้ Python standard library เท่านั้น ไม่ต้อง `pip install` ถ้าต้องการเลือกโมเดลหรือพอร์ต ให้ตั้งค่า `OLLAMA_MODEL` หรือ `LOST_LETTERS_LOCAL_PORT` ก่อนรัน `server.py`
